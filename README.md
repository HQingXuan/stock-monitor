关注你选的美股 / ETF，自动收到中文或英文行情总结。使用 Alpaca SIP 分钟行情，运行在 Cloudflare Workers + D1；仅监测，不下单。

## 什么时候收到？

| 美东时间 | 报告 | 行情覆盖窗口 |
| :--- | :--- | :--- |
| **10:16** | 🌅 开盘日报 | 09:30–10:00 |
| **12:00** | ☀️ 午间总结 | 09:30–11:44 |
| **15:30** | 🌇 下午总结 | 09:30–15:14 |

自动适配夏令时，休市日不发，半日市截止实际收盘。每个时段有 10 分钟重试窗口。

> 行情延迟至少 15 分钟，另留 1 分钟缓冲。上表窗口不含终点，报告价格是最后一分钟 K 线的收盘价，不是收到消息时的实时价格。

## 快速开始

### 先看效果，无需密钥

需要 **Node.js ≥ 22.13.0** 和 npm。

```bash
git clone https://github.com/HQingXuan/stock-monitor.git
cd stock-monitor
npm ci
npm run demo
```

模拟报告写入 `local-reports/demo.txt`，不会发送 Telegram 消息。

### 部署到自己的账户

准备 **Cloudflare 账户**、有延迟 SIP 数据权限的 **Alpaca API Key / Secret** 和一个独立的 **Telegram Bot**，然后运行：

```bash
bash scripts/setup.sh
```

向导首先让你选择 **English / 中文**，并记住选择；报告、命令回复、测试消息和项目错误提示都会使用该语言。随后验证行情权限、配置 D1 和 Worker、上传密钥、注册 webhook，并发送一条测试消息。需要 Bash（macOS、Linux 或 WSL）；请勿复用其他项目正在使用的 Bot。详细步骤和已有部署升级方法见 [配置与运维](docs/operations.md)。

语言保存为 `.setup.env` 中的 `MESSAGE_LANGUAGE=en|zh`，部署时写入 Worker 配置。旧部署未设置时仍使用中文；修改语言需要重新部署，已存报告保留原语言且不重发。Wrangler、npm 等第三方工具的输出保留原语言。详见 [语言设置](docs/operations.md#语言设置)。

## 在 Telegram 管理关注列表

| 命令 | 作用 |
| :--- | :--- |
| `/watch SPY,QQQ 7` | 添加或续期 7 个自然日 |
| `/watch GOOG,MSFT,TSM 30` | 添加或续期 30 个自然日 |
| `/list` | 查看关注列表和到期日 |
| `/stop SPY` | 停止关注 |
| `/status` | 查看最近报告状态 |

默认关注 `SPY,QQQ,TQQQ,GOOG`，最多 15 只。监控默认持续 7 个自然日（含当天），到期后用 `/watch` 续期；可指定 1–365 天。命令仅接受配置的本人私聊。

<details>
<summary><strong>如何理解报告中的数字？</strong></summary>

- 成交量是报告窗口内的累计量，与昨日及前 5 个交易日的同长度窗口比较；均量至少需要 3 个完整样本。
- 昨收参考取前一交易日最后一分钟收盘价；价格仅做拆股调整。
- 缺失数据会明确标注，不补零，也不生成涨跌结论。
- 迷你图各自缩放；成交量不表示买卖方向，报告不预测走势。

完整口径见 [数据口径与限制](docs/operations.md#数据口径与限制)。

</details>
