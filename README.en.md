Follow US stocks and ETFs with scheduled summaries in **English or Chinese**. Built with Alpaca SIP minute bars, Cloudflare Workers and D1. Monitoring only—no trading orders.

## When do reports arrive?

| Eastern Time | Report | Data window |
| :--- | :--- | :--- |
| **10:16** | 🌅 Opening report | 09:30–10:00 |
| **12:00** | ☀️ Midday summary | 09:30–11:44 |
| **15:30** | 🌇 Afternoon summary | 09:30–15:14 |

Daylight saving time is handled automatically. No reports on market holidays; shortened sessions stop at the actual market close. Each slot has a 10-minute retry window. Delivery can be delayed by the scheduler or external services.

> Data is delayed by at least 15 minutes, with an additional 1-minute buffer. Window endpoints are exclusive. The displayed price is the last minute bar’s close, not a live price at delivery.

## Quick start

### Try it without API keys

Requires **Node.js ≥ 22.13.0** and npm.

```bash
git clone https://github.com/HQingXuan/stock-monitor.git
cd stock-monitor
npm ci
MESSAGE_LANGUAGE=en npm run demo
```

The synthetic report is written to `local-reports/demo.txt`. No Telegram messages are sent.

### Deploy to your own accounts

Prepare a **Cloudflare account**, an **Alpaca API key/secret with delayed SIP access**, and a dedicated **Telegram bot**, then run:

```bash
bash scripts/setup.sh
```

First choose **English** or **中文**. Setup remembers your choice and uses it for reports, command replies, test notifications and project error messages. It then checks data access, configures D1 and the Worker, uploads secrets, registers the webhook and sends a test message.

Bash is required (macOS, Linux or WSL). Do not reuse a bot belonging to another project. The wizard changes your cloud configuration; verify actual scheduled delivery on the next trading day. Access, quotas and costs depend on your provider accounts.

### Language settings

The choice is saved as `MESSAGE_LANGUAGE=en` or `MESSAGE_LANGUAGE=zh` in the ignored `.setup.env` file and passed to the Worker as a non-secret variable during deployment.

- Fresh setup offers English by default; press Enter to keep a saved selection on subsequent runs.
- Existing deployments with no language setting continue to use Chinese.
- To change an existing deployment without rerunning setup, update `vars.MESSAGE_LANGUAGE` in your **actual deployment configuration** (usually `wrangler.local.json`) and redeploy with `npx wrangler deploy --config wrangler.local.json`. Keep `.setup.env` in sync for future deployments.
- Changing `.setup.env` alone does not update a running Worker. Stored reports keep their original language; switching languages does not resend reports.
- Project messages are translated. Wrangler, npm, Node.js and provider diagnostics may retain their original language; API status codes stay unchanged.

## Manage your watchlist in Telegram

| Command | Action |
| :--- | :--- |
| `/watch SPY,QQQ 7` | Add or renew for 7 calendar days |
| `/watch GOOG,MSFT,TSM 30` | Add or renew for 30 calendar days |
| `/list` | View watched symbols and expiration dates |
| `/stop SPY` | Stop watching a symbol |
| `/status` | View the latest report status |

Defaults: `SPY,QQQ,TQQQ,GOOG`, up to 15 symbols. Watches last 7 calendar days by default, including the day they are added. Renew with `/watch`; supported durations are 1–365 days. Commands are accepted only from the configured owner’s private chat.

<details>
<summary><strong>How should I read the numbers?</strong></summary>

- Volume is cumulative within the report window, compared with the same-length window in the previous session and up to 5 prior sessions. Average volume requires at least 3 complete samples.
- The prior-close reference is the previous session’s final minute-bar close. Prices are split-adjusted, not dividend-adjusted.
- Missing bars are flagged. They are not filled with zero volume or used to draw price-change conclusions.
- Sparklines scale independently. Volume does not identify buying/selling direction; reports do not predict prices.

</details>
